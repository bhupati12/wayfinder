# Test fixtures

`Aba_(prefecture).wikitext`, `Aioi.wikitext` and `Akajima.wikitext` are the unmodified wikitext of
the English Wikivoyage articles
[Aba (prefecture)](https://en.wikivoyage.org/wiki/Aba_(prefecture)),
[Aioi](https://en.wikivoyage.org/wiki/Aioi) and
[Akajima](https://en.wikivoyage.org/wiki/Akajima), taken from the 1 November 2026 dump.
They are by Wikivoyage contributors and licensed
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); see each article's history for
the authors.

`mini-dump.xml` is a MediaWiki export containing those three articles plus three synthetic pages
(a redirect, a talk page and a disambiguation page) that ingestion must ignore.
